# 時間軸別の価格順位：探索分析 v1

実行: `npm run study:position`。既存の private/price-study-data.json を使用し、実データ・結果は private/ にのみ保存する。本番の判定や通知は変更しない。

結果を見る前に固定する比較条件:

- 分割調整済み終値を、当日を含まない過去5・20・63・126・252・756営業日と比較する。約1週間・1ヶ月・3ヶ月・半年・1年・3年。暦日で厳密に3年前とは異なる。
- 価格順位は `(当日より安い過去終値数 + 同値数/2) / 期間日数`。安値更新は当日終値が過去最安終値を厳密に下回る場合。同値の横ばいを安値更新扱いしない。過去安値からの距離も記録する。
- 各期間について下位10%以下と安値更新を別条件にする。これは割安な企業価値、反発確率、正規分布の裾確率ではない。
- 比較期間を揃えるため全条件を756営業日の履歴が揃う日から評価する。期間ごとの長い履歴による補足比較は今回は行わない。
- 条件が成立した最初の日を採用し、続く20営業日のシグナルを除外する。21営業日以上離れた同一条件の観察日を採用。基準群は条件なしで同じ間隔。各群内の採用日は全将来期間で共通で、将来価格や到達利益で選ばない。
- 翌営業日の終値を仮の購入価格とする。5・20・63・126・252営業日後を観察。仮の往復コストを収益率から0 / 0.5 / 1ポイント差し引く。主表は0.5。配当・税・為替は含めない。
- 主比較は252営業日先まで観察できる共通事例群で、各将来期間の平均・中央値・含み損を比較する。最近の事例を落とした影響を見るため、各期間まで観察できる群も別途全保存する。
- +10%に初めて届く日数を参考として記録する。利確ルールではない。252日内到達数 / 252日観察完了数と、到達した事例だけの日数中央値を併記。未到達、追跡中、購入日のデータ未取得を別計数する。到達は終値基準で、実際に売れる指値ではない。
- 期間内下落は仮購入価格からの最悪終値収益率。ポートフォリオ最大ドローダウンではない。先に目標利益に届いた後の下落も含む固定期間の観察。
- 20日より長い将来期間には重複があり、別条件・別銘柄も相関する。事例数は独立試行数ではない。年別と、252日を空けた疎な抽出も補足する。疎な抽出は事例が非常に少なくなり得る。

既知データの探索であり、未見データでの検証ではない。最も良かった期間を利益最大化のモデルとして自動採用しない。基準群との差は投資戦略の超過収益ではない。月々の入金、買い増し、資金拘束、売却、無期限保有は再現しない。ニュースによる選別も未評価。3年安値の事例が少ない場合、長期安値の有効性について結論を出さない。

SOXLの2021年の基準指数変更と、分割以外の分配による価格変化も長期比較の制約。長期上昇・過去高値への回復は保証されない。価格が歴史的に低いことと、利益を得やすいことを別の表示にする。
