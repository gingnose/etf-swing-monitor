# 実証チェックリスト

以下は実サービス・実機も含む完了条件。ローカルでの確認結果は [P1_STATUS.md](P1_STATUS.md) に分けて記録する。外部未確認の項目は完了にしない。

## P1: 無料データと通知

- [x] SOXL / TQQQの日足を現在の無料アカウントで取得
- [ ] 市場カバレッジ、出来高、時刻、分割調整、欠損を検証
- [ ] ニュースの権限・利用条件・取得範囲を確認
- [ ] クラウドのCPU時間・AI使用量を測定
- [x] 所有者以外へのAPIアクセスを拒否
- [ ] PC停止中のAndroid通知を実機確認
- [ ] ロック・再起動・通知拒否・再登録を確認
- [x] APIキーと非公開データが公開コード・静的配信物に含まれないことを確認

## 判断と資金管理

- [ ] 予定積立と実入金を区別
- [ ] 資金残高を超える買い増し候補を出さない
- [ ] 米ドル・コスト込みで利益条件を検証
- [ ] 含み損または利益判定不能時に利確候補を出さない
- [ ] AIが損失時の売却禁止ルールを上書きしない
- [ ] 仮想売買は含み損と入出金を含めて評価
- [ ] 記事取得時刻以後の情報だけを使う

## 通知運用

- [x] JSTの日付境界・同時実行・再試行で通知上限を守る（自動テスト）
- [ ] データ欠損や分析失敗時に古い判断を流用しない
- [ ] 監視停止をアプリ内で確認できる
- [ ] 月額0円を維持し、無料枠超過時は削減・停止する
- [ ] バックアップから復元できる

Androidへの予約通知到着は本人確認済み。PC停止・ロック・再起動という個別条件は確認を残す。価格履歴・指標・CPU分割の検証は [DATA_PHASE.md](DATA_PHASE.md) を参照。
