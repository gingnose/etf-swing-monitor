# ニュースの優先表示と購入前の補助確認

価格条件を主判定とし、ニュースは「下落に慎重に判断すべき材料がないか」を確認するために使います。ニュース単独の購入・売却推奨は生成しません。価格ルールの有効性は未確認で、買い目・売り目通知は未実装です。

## 画面

`news-priority-v1` は英語見出し・固定タグ・配信元を使う説明可能なルールです。AIや本文分析ではありません。悪材料・懸念材料を優先し、直近7日の重要な記事を最大5件表示します。残りは「参考記事も含めて表示」で確認できます。良材料も残し、各記事に優先理由・方向の推定・未確認事項を表示します。

直近80記事を検査してURL重複をまとめ、直近7日を先にし、その中で懸念と重要度の順に並べた40件が表示対象です。全ニュースからの選別ではなく、取得窓の外は評価していません。スコアは並び順のための固定値で、上昇確率・予測リターン・検証済みの精度ではありません。

価格条件の各銘柄に、直近7日の取得見出しから作った補助確認を併記します。

- 懸念材料あり：否定・噂を含む要確認候補もあり、悪材料が確定した意味ではありません。
- 取得した見出しの範囲では懸念材料を検出せず：関連見出しがあり、3情報源の最終成功が2時間以内の場合だけ表示。悪材料なし・購入可の判定ではありません。
- ニュース確認不足：未取得、失敗、古い取得、関連見出しなしの場合。価格条件への一致を購入可へ昇格させません。

情報源の一部失敗は懸念材料があっても明示します。下落との因果、企業価値に対する割安さ、現在のETF構成比、材料の織り込みは判定しません。表示は確認日時時点の結果です。

## 通知

特に重要かつ悪材料・懸念材料に分類できる新情報だけが対象。良材料は画面表示のみです。重大事実の検出範囲は、主要企業（NVIDIA/AMD/Microsoft）の明示的な見通し変更、米国の半導体輸出措置、FRBの明示的な政策決定などに限定します。一般的なキーワード一致だけでは通知しません。政策の方向は単純に好悪を断定しません。

見出しの主語・動詞・関連性・配信元から判定し、予想・噂・否定・解説・複数の節を含む曖昧な表現は通知を抑制します。ただし消費電力・コスト・事故の深刻度の低下を悪材料として扱わない回帰ケースも設けています。英語の全表現に対応するものではなく、誤検出・見逃しがあります。単独報道の本文や事実を確認済みとは扱いません。通知にも「見出しによる推定」を明記します。

毎時40分に候補を選び、45分に送信を試行します。最新40記事の中から公開24時間以内、初回取得した記事版と取得元の成功が2時間以内、有効化以降の版だけが対象です。有効化前に保存した記事を遡って一斉通知しません。手動のニュース取得だけでは即時送信しません。

送信直前に記事版・取得状態・ルール版・30分の待ち期限を再検証します。同じ種別・主体・方向の材料は72時間抑制します（日をまたぐ転載も対象）。これは粗い出来事のまとまりで、同種の別の重要事実も抑制する場合があります。

既存の予約テストと同じJSTの日次予約テーブルを使い、自動通知は合計1日1回。最初の対象を送った日は後続を送らず、その日の最重要ニュースを後から保証するものではありません。同時実行は原子的に予約し、送信結果が不明でも再送しません。端末への到着保証はありません。

## 今後の精度検証

現在は通知基盤と選別ルールの動作を検証しています。実データに対する適合率・見逃し率、価格とニュースを組み合わせた運用成績は未評価です。買い目通知への接続には、価格ルールの有効性、本文と一次資料の照合、通知候補の実時間評価が必要です。過去に得られなかった記事を使って過去の判断を評価しないよう、記事版と初回取得日時を保持します。
