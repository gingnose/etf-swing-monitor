# SOXL/TQQQ 銘柄別の乖離指標の比較

実験仕様 `price-calibration-v1`。2026-09-27に結果を見る前に候補・閾値を定義。既に見た2019年以降のデータを利用する探索分析であり、未見データでの実証とは呼ばない。本番の価格ルール・自動購入/売却通知は変更しない。

## 固定した候補

20日平均と母標準偏差の価格zを基準とし、同じ20日窓の対数価格z、対数価格の中央値とMADで測るz、SMA20からの対数乖離の過去252観測内での順位を比較する。順位の母集団には当日を含めず、当日以前の情報だけを使う。MADの1.4826は正規分布との尺度合わせの慣例であり、正規分布や反発確率を仮定しない。

中心比較は、価格z≤−2、同条件に上昇傾向を追加、−2σ内への回復＋上昇傾向、対数z≤−2＋上昇傾向、順位≤10%＋上昇傾向、MAD z≤−2＋上昇傾向。上昇傾向は終値>SMA200、SMA50>SMA200、SMA50が5営業日前より高い場合と固定する。

感度分析は価格zの−1.5/−2.5/−3と順位5%/15%。最良の閾値を見つける探索には使わず、全結果を保存する。上側2σ・順位上位10%も、その後の値動きを調べる出口の診断として計算する。実際の売却ルールとはしない。

## 評価方法

全候補の開始を272番目の観測に揃える。期間は2019〜2023年と2024年以降に分ける。シグナル翌営業日終値を開始価格として10/20営業日後を測り、仮の往復コスト0/0.5/1%を控除する。同一群では保有窓の重複を除外。期間境界を越える観測は未完了。期間中の最悪下落は終値ベースであり、日中の最大下落ではない。

比較用に条件なし・上昇傾向のみのイベント分析を置く。開始日・件数が異なるため、単純な平均差を戦略の超過利益とは解釈しない。各候補の年別および、事前20日リターン標準偏差が過去252観測の中央値より高い/低い局面も分ける。σ超過頻度は重複する全営業日の記述統計であり、独立した標本ではない。

これは実際の売買・損切りなし・買い増し・資金配分を再現する検証ではない。未決済の資金拘束、配当、税、為替、約定、現在の指数と過去の指数の差を完全には扱わない。SOXLの基準指数は2021年に変更されており、年別結果も確認する。

収益性を証明した候補を選ぶ作業ではなく、表示モデルとしての解釈性と、次に前向き検証する候補を絞る作業とする。実データ・集計はprivateに保存し、公開コードに再配布しない。

## 実行方法と確認状況

`npm run study:calibration`。先に `npm run study:prices` で取得した `private/price-study-data.json` を読みます。新規のクラウド処理・課金・自動売買・本番の判定変更はありません。結果は `private/price-calibration-report.json` と `.md` に保存します。生データ・集計とも公開Gitへ追加しません。

2026-09-27に2019年開始・2026-09-25終了の各1,944日を利用し、共通ウォームアップ後の各1,673日（2020-01-30以降）で実施。13条件と2比較群、2期間、2保有期間、3コスト条件の全結果を保存しました。候補の結果を見た後に閾値は変更していません。期間差・少数標本があり、実用の購入通知へ採用する優位性は確認できていません。

計算の単位不変性、母標準偏差、過去のみの順位、未来データの非混入、ゼロ分散、実行時刻・コスト・重複・期間境界をテスト。主要なσ頻度と12群のイベント分析を別のPython実装でも再計算しました。
