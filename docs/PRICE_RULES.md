# 価格条件の検証フェーズ

ルール版 `price-hypotheses-v1`。購入額は本人が決めます。割合上限や数量の自動提案は設定しません。

## 今回の実装

所有者専用画面で「価格ルールの検証」を表示します。条件一致・条件待ち・価格条件による買い増し見送り・履歴不足を分け、数値と根拠を併記します。売却候補は出しません。ニュースと予算は未評価で、買い通知も有効にしません。

最新の確定日足が取得できているときだけ判定します。SIP・分割調整・両銘柄の日付一致を要求します。欠損・期限切れ・取得失敗では現在の判定を保留し、過去の観測を今日の判断として再利用しません。

- 共通条件: 終値 > SMA200、SMA50 > SMA200、SMA50 > 5営業日前のSMA50、RSI14 ≤ 70。
- 押し目: 共通条件に加え、昨日と今日の終値が各日のSMA20未満、今日は前日比上昇、RSI14は40〜60。
- 回復確認: 共通条件に加え、昨日の終値 ≤ 昨日のSMA20、今日の終値 > 今日のSMA20、RSI14は45〜65。

閾値は初回の実データ評価前に固定した仮説であり、有効性を確認した数値ではありません。実データの成績を見て閾値を変更していません。過去検証と本番で計算を揃えるため、毎回直近205営業日の終値から計算します。RSI初期化期間の違いにより、全取得期間を使う既存の参考指標と微差が出る場合があります。

## 過去のイベント分析

`npm run study:prices` でAlpacaから2019年以降の終値と取引日カレンダーを取得します。APIの終了時刻はUTCの明示的な日時を指定し、現在のNY取引日を除外します。最初の日付だけの指定は403になったため、日時を明示して解消しました。取得元や料金プランは変更していません。

2026-09-26の実行では、両銘柄とも2026-09-25までの1,944営業日を取得し、カレンダーと一致しました。生データと個別観測・集計レポートは `private/` に保存し、コミットしません。`--reuse` は保存済みデータで再計算します。

- 前期2019〜2023年・後期2024年以降に時間分割。窓の終点が期間境界を越える観測は未完了扱いとします。
- 条件成立の翌営業日**終値**を開始価格とし、その10または20営業日後の終値までの変化を測定。同日終値で購入したとは仮定しません。
- 同一銘柄・条件・期間・保有期間の群内では観測期間の重複を除外します。別条件・銘柄間の独立性は保証しません。
- 完了数、未完了数、重複除外数、平均、中央値、プラス割合、最悪の終点変化、開始価格からの最悪下落を記録します。これは総資産の最大ドローダウンではありません。
- 仮の往復コスト0%・0.5%・1%を変化率から差し引く感度分析。実際の証券会社手数料とは別です。
- 条件なしの比較群は各期間の最初の評価可能日から同じ非重複ルールで抽出します。開始日と件数が異なるため、群の平均差を戦略の超過利益とはみなしません。

売却を実行するシミュレーションではなく、条件後の値動きの記述分析です。予算・再投資・税・配当・為替・実約定・資金拘束・ニュースを含みません。プラス割合を勝率・将来確率として表示しません。前後の時間分割は実時間の未見データ検証でもありません。銘柄選択や改訂済み価格を使う限界も残ります。

初回の結果は期間と条件で一貫せず、後期には平均マイナスとなる群もありました。条件一致だけを実用の買い通知へ昇格させる根拠は得られていません。閾値を都合よく調整せず、原版の結果を保持します。

`node --experimental-strip-types scripts/upload-price-study.mjs` は、20営業日・仮コスト0.5%の集計だけを所有者専用D1へ保存します。同じルール版の初回評価は上書きしません。公開コードに実価格・レポートは含めません。

## 今後の観測

既存の定期価格更新とCPU枠を分け、JST 9/15/21時20分頃に観測を保存します。価格が揃わなければ保存しません。通知の予約処理が優先された場合は、その回の観測はスキップされます。

ルール版・米国取引日を一意とし、同日の初回観測時刻・入力ハッシュ・判定値を原子的に保存します。同時実行でも1件、後日の価格修正で初回記録を書き換えません。保持は1年、画面は直近30取引日です。「現在の条件を観測に保存」も同じ制約です。

観測日と入力ハッシュにより、後から既存の価格履歴と照合できます。将来の結果の自動集計、ニュース追加効果、資金制約込みの運用検証は後続工程です。
