# P1 接続実証の状況

2026-09-26

**接続確認版の実装とローカル検証は完了。P1全体は未完了です。**
Alpacaから両銘柄のSIP日足取得、Cloudflareへの配置、D1マイグレーション、Secrets登録まで完了。公開URL経由の所有者認証・実データ保存も確認済み。Androidではホーム画面への追加・ログイン・価格表示・予約通知の到着を本人が確認済みです。

## 実装済み

- Android向けPWA（ホーム画面用manifestとアイコン、通知用Service Worker）。
- 所有者キーでのログイン、HttpOnlyセッション、CSRF対策、ログアウト。
- Alpacaの日足取得。両銘柄の欠損・古いデータ・権限エラー時は失敗扱い。
- 実データがない画面では価格を空欄表示。売買シグナルは表示しない。
- Web Push登録、即時テスト、約5〜10分後の予約テスト。
- JSTの自動通知1日1件上限、同時実行対策、期限切れ予約の破棄。
- 通知用公開鍵の曲線検証と、通知先の許可リスト。
- 秘密情報のローカル生成、Cloudflare Secret登録用のスクリプト。
- 1日3回の価格取得用Cron（初期無効）、使用履歴の保存期間制限。

単体テストの暗号化送信では通信を置換しています。別途、本番の予約通知はDB上で `accepted` を確認し、本人からAndroidへの到着報告を受けました。
自動画面テストはローカルChromeです。Androidでのインストール・ログイン・価格表示・予約通知到着は本人確認に基づきます。PC停止・画面ロック・端末再起動という個別条件は未確認として残します。
公開時のCI結果はGitHub Actions上で別途確認できます。

外部通信のリダイレクト設定は、クラウド接続で失敗した `error` から `manual` に変更しました。転送先へ自動追跡せず、3xxは失敗とするため、資格情報を転送しません。この変更後にクラウドからのAlpaca取得が成功しています。
